Music SVG glyphs

This folder stores all note/rest/group graphics as standalone SVG files.
You can replace any glyph by editing one file without touching React code.

Naming keys used by NoteRenderer:
- Notes: whole-note, half-note, quarter-note, eighth-note, sixteenth-note
- Rests: whole-rest, half-rest, quarter-rest, eighth-rest, sixteenth-rest
- Groups: eighth-pair, two-sixteenth-and-eighth, eighth-and-two-sixteenth, four-sixteenth,
          sixteenth-eighth-sixteenth, dotted-eighth-sixteenth, sixteenth-dotted-eighth, triplet-eighth
